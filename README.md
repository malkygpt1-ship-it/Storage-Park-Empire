# Storage Park Empire

A browser-based UK self-storage park tycoon game, built with Next.js and designed for Vercel.

## First playable draft

The initial vertical slice includes:

- UK market selection with regional demand, planning, competition, land and rent indicators
- A live Deal Room containing development land and operating storage parks
- Cash, portfolio value, debt and monthly cashflow tracking
- Automatic acquisition finance when cash is insufficient
- Monthly progression with occupancy ramp and operating costs
- Responsive dark property-investment dashboard UI

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import the repository into Vercel. The app uses the standard Next.js build command and does not require environment variables for this draft.
